# Muse街 PNG 素材セット v1

配色 A「焼き瓦と柳」の、[地図 P0](../../tools/town-mock/README.md) に使う原寸素材です。地形・店舗・公共施設はチャンクの座標で組み立てます。

| ファイル | 中身 |
| --- | --- |
| `tiles-v1.png` | 32×32px の地形と小物。草地などの差分、川と園路の接続、戸口の敷石を含みます。 |
| `objects-v1.png` | 3幅の橋、公共施設、地区の目印、S/M/Lの北・南向き店舗の固定色部分、改装中の足場。 |
| `shop-masks-v1.png` | 店舗の同寸のアルファマスク。屋根5段、入口4段、壁3段、縁2段の順で、指定色を合成します。 |
| `tileset-v1.json` | 素材名、元画像の矩形、接続、店舗のサイズ・戸口位置、着色の段と配色。 |
| `tileset-v1.js` | ファイルを直接開く場合の、同じマニフェストのスクリプト版。 |

地形・小物のIDは `TownGen.GROUND` と `TownGen.DECO` で定義します。地形の差分はワールド座標から選びます。岸と園路の配列索引は北1・南2・西4・東8のビット和です。川の幅は64px、橋は南北方向に128pxで、道幅に応じて32・64・96px幅を使います。

店舗は64・128・192px角で、枠は敷地内に収めます。`shops` の `front` は原寸画像の上端から戸口の接地点までの距離です。北向きLの `rear` は裏口の踏み場です。屋根と入口は別マスクで、北向きLの表の庇と裏口の扉は同じ入口マスクで着色します。固定色部分に、必要な色を各マスクのアルファで合成します。ブラウザではサイズ、向き、配色ごとに合成結果を再利用します。

建物・橋・区画の配置座標は [チャンクのJSON](../../tools/town-mock/tiles.html) を参照。旧版のPNGを置き換える場合は、PNG・マニフェスト・参照名の版を一緒に上げます。

`node tools/town-mock/check-tiles.mjs` でPNGの寸法、素材の参照と色マスクの寸法、121店・200店の配置で使う素材の揃い方を確認できます。
