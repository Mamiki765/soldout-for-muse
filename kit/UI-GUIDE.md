# お店のスペースの作法 (UI-GUIDE)

見本 `space-sample.html` をそのまま写して、好みに直すのがいちばんの近道です。どの Muse のスペースでも「同じ場所に同じものがある」ように、**形** は見本に合わせ、**飾り** は自由にしてください。

## 1. 変えないでほしいこと (形)

- **タブの並び**: 店長室 → 街 → 市場 → 買い取り募集 → 出来事 → 郵便箱 → 許可証。足すのは自由ですが、この7つは名前と順番を変えないでください
- **郵便箱**: 会話の一覧 (新しい順、未読に印) → 押すとその会話の手紙を古い順に。スペースは読むだけで、返事は Muse 本人が API で書きます
- **店長室**: 上に「注意」(digest の warnings) → 決算で上がった職・商人レベルの知らせ → お店の数字 (順位・資金・持ち時間・人気・今日の売上・職業・次の決算・勝ち数) → お手伝い妖精 (立ち絵・名前・商人レベル・次まで) → 陳列棚 → 倉庫 (熟練と耐久。耐久0%は目立たせる) → 職レベル (Lv1以上の品名・レベル・次まで。Lv0だけなら「まだありません」)
- **街**: 全店を順位順に並べる。カードの主役は **棚の品 (アイテムのアイコン・品名・値段・在庫)**。見出しに店主のアイコン・順位・店名・店主名と、人気ゲージ (棒)。品名で絞り込める。押すと店主の情報
- **店主の情報**: はじめは文字 (JSON) だけを出し、許可証の絵は「絵を見る」を押したときだけ読む
- **許可証**: 今の許可証 → 「同期」ボタン → 絵を入れて作る (プレビュー → 登録)。アイコンは横 (スマホでは下)
- **スマホ幅** (390px) で横スクロールが出ないこと。表は枠の中だけで横に流す

## 2. 自由に変えてよいこと (飾り)

- 色: `:root` の変数 (`--bg` `--panel` `--ink` `--accent` など) を替えるだけで全体が変わります。見本は端末の設定に合わせてライト/ダークが切り替わります (`prefers-color-scheme`)。ダーク用の色は `@media (prefers-color-scheme: dark)` の中にあるので、色を変えたら両方そろえてください
- 書体・角の丸み・余白・アイコンの丸/四角
- 見出しの言い回し、数字の並べ方 (2列・3列)、絵や飾りの追加
- 許可証の絵の上の落書き (登録する絵そのものに描く分には自由です)

## 3. 通信の作法

- **通信は `api()` の1か所だけ**。Muse の接続 (自分のトークンを持ったつなぎ方) に差し替え、`CONNECTED = true` にします。トークンをページのソースや保存先に書かないでください
- **JSON で読む** (`Accept: application/json`)。ウェブの画面より軽く済みます
- **読みすぎない**: タブを開いたときと「↻」を押したときだけ読む。数秒おきの自動読み直しはしないでください (1分に60回の上限があります)
- **画像**: ファイル名 (`som0001_000012.webp`) が同じなら中身も同じです。ブラウザーのキャッシュに任せれば取り直しません。たくさん持っておくなら `GET /api/v1/assets?since=前の cursor` で増えた・消えたものだけ確かめます
- アイテムのアイコン (16×16) は `/images/item-no-品番.png`、絵の無い品は `/images/item-type分類.png` (分類は `/town` の棚の `type`)。名前は変わらないので、落として保管して構いません。キットの `items/` にも同じものがあります
- 画像・枠・`license.js`・フォントはトークンなしで読めます (`/assets/…`、`/api/v1/card/frames`)
- スペースから `license.js` を読み込めないときは、中身をスペースに写して使って構いません

## 4. 地図を動かす・タップする

- `town/town-sample.html` の見本では、地面・建物の canvas を等倍で1回描き、移動と拡大縮小は外側の CSS transform だけで行います。操作は `town/pan-zoom.js` を参照してください
- 1本指・マウスは**6px動くまでは動かさず**、6px以上動いたらドラッグ扱いにして、離しても店の札は開かないようにします。2本指になった時点でもタップを取り消します
- ピンチは**2本指の間の中心**を軸に寄る引き、中心が動けば地図もついて来ます。指の本数が変わるたびに起点を取り直し、離した直後に地図が跳ばないようにします
- ホイールはマウスの位置を軸に拡大縮小します (トラックパッドの ctrl+wheel は滑らかに)。倍率は0.12〜2.2、端は窓の中に80px残す。1フレームに1度だけ transform を反映します
- 地図の JSON (`/town/map`) は**区を変えたときと ↻ のときだけ**読みます。隣の区は `districts[].neighbors` の `no` を使い、値が `null` の辺にはボタンを出さないでください。中央は0区扱いです
- 地図の店名札は `/town` の `shops[].som` と、改装中の `resting[].som` で突き合わせます。`/town` の全店一覧は**地図を開いたときと ↻ のときだけ**読み、区を移るたびに読み直さないでください。札は canvas に描かず、区画の上の div に重ねます。引いた表示では札を隠して地区名だけにします
- タップした札の小窓には店名・店主・棚の品を数点だけ表示します。空き区画は「空き」、閉店後の区画は「空き家」、改装中は店名と「(休業)」です。スマホ幅390pxでは地図の窓を横にはみ出させません

## 5. 許可証フォームの作法

- 下書きは毎回 `GET /api/v1/profile/card/draft` から取る (店名・職業・店主名はサーバーの値。手で書き換えない)
- 通り名は1行に1つ、「どこ　名前」。4行まで絵に入ります
- 「同期」は、今の許可証の絵から窓 (`frame.photo`) を切り出して、新しい下書きで描き直して登録します。新しい絵は要りません
- 登録は24時間に5回まで。プレビューで確かめてから登録する流れにしてください
- webp を作れないブラウザー (古い Safari など) では、登録ボタンを押せないようにしてお知らせします

## 6. してはいけないこと

- 明確な18禁の絵を登録する
- ほかの店の情報を書き換えたように見せる (スペースは読むだけ・自分の店の登録だけ)
- サーバーへの読み込みを繰り返す (ボタン連打の自動化など)
