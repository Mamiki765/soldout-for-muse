# ミューズ街 P0 見本（tools/town-mock）

1.2.0 で予定している「街の地図・住所」の**見本**です。本体（`src/`）には入らず、本番の DB にも触りません。店・店主・地区・通りの名前はダミーです。地図には A「焼き瓦と柳」の [PNG 素材](../../kit/town/README.md) を使います。

前提は設計書 第2版（プロジェクトの `soldout/2026-11-22-town-map-housing-portrait-design.md`）です。

## 開き方

`index.html` をブラウザで開く（ファイルを直接開けば動く。サーバーは要らない）。

- `ui1.html` … UI案1 地図＋横の札
- `ui2.html` … UI案2 全画面の地図＋浮かぶ札
- `ui3.html` … UI案3 一覧と地図の二画面
- `tiles.html` … PNG チップ一覧・外観プリセット・地区1つのチャンク・チャンクの大きさの比べ・JSON
- `front.html` … 今の観戦画面に地図を入れた見本（`?page=top|town|owner|room`、札は `&fuda=parch|classic`）。設計はプロジェクトの `soldout/2026-11-22-town-front-design.md`
- `license.html` … 許可証の見本（横長・縦長・正方形・旧許可証＋住所）

URL の `?center=admin` で中央に管理人の店（som0002）を入れる案、`?names=b` で地区名の案B、`?shops=200` で200店（後から79店を入れる）、`?avenue=2` で大通り64px（既定96px）、`?alley=1` で路地32px（既定64px）、`?cols=8` で地区を8×4区画（既定6×4）に切り替えられます。

## 中身

- `town-gen.js` … 街の生成。区画（3×3 敷地＝6×6 チップ＝192px）、地区（路地2本×両側＝24区画）、大通り、左隣・右隣・向かい・目印、初めの配置（ブロック → おたがいの希望 → ランダム、各地区8割まで）、後から来た店の割り当て、閉店の猶予と NPC の家。
- 地形: 川（64px）と並木は地区の列 `gy` で決まり（偶数=川、奇数=並木）、地区をまたいで街の外まで続く。大通り・中央通りが川を渡る所は橋（両岸へ1マス延ばす）。チャンクは「自分の地区＋西と北の大通り」だけを持ち、重ならない。地区のまわり1マスは「街の外」チャンク（野原・畑・林）。
- 中央は横に2チャンク：西（d01）は公共施設、東（d02）は大きな公園と将来の施設の予定地（花壇・遊歩道・石畳・緑地）。あいだの大通りは石畳の中央軸。どちらも店の配置・引っ越しの対象外。まわりの地区は中央の2マスを囲む輪で時計回りに置く（`townCells`）。
- `town-gen.js` の `chunkAt()` / `chunksFor()` / `chunkData()` … Muse に渡す地区ごとのチャンク（地面・小物の番号のマス目、建物、目印、区画）。API案 `GET /town/chunks/{id}`。`aroundJson()` は「まわりを見る」（API案 `GET /town/lots/{id}/around?scope=street|district`）。
- `tiles.js` … PNG アトラスをチャンクに沿って描く。店舗は屋根と入口を独立して着色。北向き L は表の庇と裏口に入口色が入る。
- `common.js` / `mock.css` … 3案共通の部品（上から見た地図、店の札、まわり、見出しの切り替え、街暦の置き場）。視点は上から見る地図に決まった（2026-11-22）。本命は UI案2。
- `check.mjs` … 配置の決まりの検査。`check-tiles.mjs` … PNG、アトラスの参照、121店・200店で使う素材の検査。

```
node tools/town-mock/check.mjs
node tools/town-mock/check-tiles.mjs
```

確かめること：同じ種なら同じ配置／121→200 で前からいる店の区画が変わらない／1人1区画・重なりなし・道にはみ出さない／道がすべてつながり、どの店先からも広場まで行ける／ブロックし合う2人が左右・向かいにいない／おたがいの希望が隣・向かい・同じ通り（後から来た店は同じ地区まで）／隣・向かいはいつも同じ路地／初めの配置は各地区8割まで／NPC の家の見た目は区画で決まる／猶予切れで空き家だけが NPC の家に戻る。
