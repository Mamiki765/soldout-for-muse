SOLD OUT ミューズ街 P0 見本

本体には入らない見本。店・名前はすべてダミー、絵は仮のマップチップ

設計書 第2版（S は無料の店兼家、全店に 3×3 敷地の区画）を前提に、上から見る地図で、画面の作りと操作がちがう UI を3案作った。どれも同じ街（121店 → 200店に増やせる）を使う。中央地区の「噴水通り」はどの案でも同じ並び（おたがいに希望した2店・偶然の向かい2店・休業の店・空き家・NPCの家・新しく入った店）。

UI案1 地図＋横の札地図の右に札（スマホは下から出る札）。全景／地区を切り替え、＋－で寄る。マウスを乗せると店名。 UI案2 全画面の地図＋浮かぶ札画面いっぱいの地図をドラッグ・ホイール・二本指で動かす。札は店のそばに浮かぶ。地区の見出しと右下の小さな地図で移動。 UI案3 一覧と地図の二画面左に通りごとの一覧と札、右に地図。一覧に指を乗せると地図が光る。スマホは「一覧／地図」のタブ。 マップチップと Muse に渡すチャンク仮のチップ一覧（番号つき）、外観のプリセット、地区1つを 32px で、チャンクの大きさの比べ、JSON。 許可証の見本横長・縦長・正方形と、旧許可証＋住所。3:4／1:1／未提出を切り替え。

3案の比べ方

UI案1 地図＋横の札UI案2 全画面の地図＋浮かぶ札UI案3 一覧と地図の二画面
画面の作り地図（左）と札（右 360px）の2列。スマホは地図＋下から出る札地図が画面いっぱい。地区の見出し（上）・小さな地図（右下）・札（店のそば）が重なる一覧（左 380px）と地図（右）の2列。スマホはタブで切り替え
動かし方スクロール＋「＋－」ボタン。全景／地区の切り替えドラッグ・ホイール・二本指で自由に。ゲームの地図に近い一覧の行を押す。地図は選んだ地区とまわり（地続き）を出す
全景全地区を縮めて目印の名前を重ねる引くと全地区。小さな地図で今いる場所が赤枠地区の選択（目印つき）。全体の絵は出さない
店を選んだとき右の札。札の下で S/M/L を切り替えて増築の見え方店のそばに札が浮かぶ。地図から目を離さない左の一番上に札。一覧の行も光る
住所 → 店先どの案も「許可証の住所を押す」→ その区画に寄って赤枠、札の「左隣・右隣・向かい」でお隣へ移る
PC のマウス乗せると店名と住所（乗せる案内は無し。押すと札）一覧に乗せると地図の区画が光る
スマホ素直。札が画面の半分を使う操作は気持ちいいが、見出しや札が地図を隠しやすい一番使いやすい（一覧が主、地図は確認）
観戦と API観戦は地図と札。API は地区ごとの区画・持ち主（GET /town/map）と札の中身（GET /lots/{id}、左右・向かい・目印）。UI案3 の一覧は API の並びとほぼ同じなので、Muse のスペースにも写しやすい
実装の重さ軽い〜中中（ドラッグ・ピンチ・小さな地図・札の位置合わせ）中（一覧と地図を同期させる）
200店以上平気（地区ごと）平気。引いたときの描画が一番重い（全地区を1枚で持つ）一番平気（地図は近くの地区だけ）

組み合わせもできる：たとえば「PC は UI案2、スマホは UI案3 のタブ」や「UI案1 に UI案3 の検索を足す」。

切り替え

第3弾（11/22）：中央の1チャンクを公共地区に（街役場・ギルド会館・大きな樹・噴水広場・掲示板・中央市場・船着き場）。南北に中央通りが抜け、川を64pxの橋で渡る。川と並木は列ごとに決まり、地区をまたいで街の外まで続く。大通りが川を渡る所は96pxの橋。チャンクは重ならない（各チャンクは自分の地区＋西と北の大通り）。地区名は地形と目印に結び付けた案A／案B。「中央」で公共施設だけ／管理人の店入りを切り替え。

第2弾（11/22）：UI案2を本命に。家の大きさは棚の数で決まる（S 1〜4棚 64px／M 5〜7棚 128px／L 8棚 192px、区画はどの店も 192px 四方、家の維持費は無く棚の維持費だけ）。地図は Muse に渡すチャンク（地区ごとのマス目）と同じデータから canvas で描く。外観はプリセット＋屋根・ドアの色（UI案2の札で試せる）。札の左右・向かいは常には出さず「まわりを見る」で通りの両側か地区ぜんぶを取る。見出しに「ミューズ街 第○期」の置き場。

各画面の上で、店数 121／200（79店を後から入れて、前からいる店の区画が変わらないことを見る）、大通り 96px／64px、路地 64px／32px、地区の幅 6×4／8×4区画を切り替えられる（スマホは「切り替え」を押す）。node tools/town-mock/check.mjs で配置の決まり（重なりなし・道がつながる・ブロック・希望・121→200 で動かない など）を確かめられる。
