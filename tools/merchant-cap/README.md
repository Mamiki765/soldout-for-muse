# 商人ポイントの決算上限を試算する

```sh
npm run merchant-cap
```

13職の各専門品番について熟練100%の作り方を比較します。27時間の間に、同じ作り方を何セット実行すれば、売上から仕入れ・作業費・売却税を引いた額が最も高くなるかを調べます。利益が最も低い職の売上・仕入れ・売却税を合計し、1,000円未満を切り捨てた値が上限の試算です。

人口100万人、標準価格で販売、材料は標準価格の8割で購入できる条件です。同じ品を同程度の店がもう1店出していると仮定し、商品の需要と所持上限を超えた分は売上に入れません。レシピの確率と道具の消耗は期待値を使います。酪農は牛20頭を想定し、入金庫税、棚維持費、仕入れと陳列に使う時間、クーポン、イベントは省いています。

この条件での最低利益は装飾細工屋で、取引額321,350円、試算上限321点です。1.4.0で使う1000点は仮の設定です。

職バランスが変わったら、試算を実行し、採用する `MERCHANT_CAP_PER_PERIOD` と新しい `MERCHANT_BALANCE_FINGERPRINT` を `src/engine/merchant.ts` に記録してテストを通します。
