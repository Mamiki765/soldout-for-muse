# 商人ポイントの決算上限を試算する

```sh
npm run merchant-cap
```

13職の各専門品番について熟練100%の作り方を比較します。27時間の間に、同じ作り方を何セット実行すれば、売上から仕入れ・作業費・売却税を引いた額が最も高くなるかを調べます。その売上・仕入れ・売却税の合計に現行の職補正と決算上限を適用した点数も表示します。

人口100万人、標準価格で販売、材料は標準価格の8割で購入できる条件です。同じ品を同程度の店がもう1店出していると仮定し、商品の需要と所持上限を超えた分は売上に入れません。レシピの確率と道具の消耗は期待値を使います。酪農は牛20頭を想定し、入金庫税、棚維持費、仕入れと陳列に使う時間、クーポン、イベントは省いています。

1.4.0の上限は2,000点です。職補正の設定には、1職1店・棚8・34.7時間/決算でイベントも含めた別の比較を使っています。このコマンドは単一工程による確認用です。

職バランスが変わったら試算を行い、決算上限 `MERCHANT_CAP_PER_PERIOD` と職補正表 `MERCHANT_JOB_MULTIPLIER` を見直します。採用した数値に対する指紋 `MERCHANT_BALANCE_FINGERPRINT` を更新してテストを通します。
