# 熟練の共有（酪農家）案

**状態: 案。数値は管理者の確認待ち。** 版番号と更新履歴は触っていません。

## 何が困っていたか

- 酪農家に転職すると、熟練は **ミノタウロス♀ (25)** に集まる。でも搾乳は熟練で時間が変わらない (time = exptime) ので、この熟練は何にも効いていなかった。
- ヨーグルト〜チーズケーキは **ミノ牛乳 (26)** の使い方で、熟練なし・時間固定。続けても速くならない（他の職にある「熟練のごほうび」が酪農家にだけ無い）。
- ミノ牛乳に別の熟練を付けると、決算ごとの減り (6%+5) が2か所に割れ、使わない側が下がる（v0.3.0 草案6章の問題）。

## 変えたこと

`tools/skill-share.json` で「ミノ牛乳の使い方はミノタウロス♀の熟練を使う」と決める。

- ミノ牛乳の **物を作る使い方すべて**（ヨーグルト・チーズ・クリーム・ジェラート・チーズケーキ。後から足す品も自動で対象）:
  - 今の時間 = 熟練0の時間（始めやすさはそのまま）
  - 熟練最大で **3/4 の時間**
  - 1セットで熟練 +1%（ミノタウロス♀に入る）
- 「飲む」は変えない。搾乳の時間も変えない（原作どおり）。
- 熟練はミノタウロス♀の1か所だけなので、熟練の合計は増えず、技術書を失う抽選にも近づかない。
- `GET /api/v1/items/26` に `skill_item`（テキストは「熟練はミノタウロス♀と共通」）を出す。
- エンジンは `ItemDef.expitem`（無ければ自分）を見るだけの小改修。他の品の挙動は変わらない。

酪農家の最大は上位の帯に入り、頂点（杖・鎧）は超えない。最大半分の時間にすると 5.3〜5.5万で杖を超えるので見送り。

### イベントの期待値

- 乳製品ブーム（startproba 100 = 1日0.1回、6〜30時間、平均18時間）は、開催している時間が全体の約7%。その間だけ客が1.5倍なので、平均すると需要は約+3.5%。この PR ではイベントの数値は変えていない。
- ジェラート・チーズケーキは1セットで街の需要のおよそ1日分ができる。速く作れても売れる数は需要で頭打ちなので、効き方は「売上が増える」より「浮いた時間でほかのことができる」が主。ブームの間は売れる数が増えるので、速さが実際の売上に効くのは主にブーム中。
- 熟練を保つのは楽（搾乳も製作も1回+1%）。決算ごとの減りを埋めるには27時間に6〜7回で足りる。
