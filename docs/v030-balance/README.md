## ねらい

職業ごとの稼ぎを、熟練最大・職業ボーナスあり・標準価格で比べました。1時間あたりの利益です。上位（ミスリルの杖 3.9万、ミスリルの鎧 3.5万、ミスリル鉱山 3.3万）に対して、薬屋 0.24万、酪農家 0.4万、本屋 1.6万、行商人 2.0万と大きな差がありました。

そこで、弱い職業に「看板の新ライン」を1本ずつ足します。上位の帯（2.4〜3.0万）に入れて、頂点は超えないようにします。

- 期待個数は、街の1日の需要（1,000,000 ÷ popular）に合わせます。
- 率（期待売上 ÷ 材料費）は、完成品が1.3〜1.8、中間素材が1.6〜2.3です。
- 1セットの利益は、ミスリルの鎧（約5.3万）以下にします。

### 熟練の置き場

熟練は品ごとに決算のたびに 6%＋5 減ります。新しい本や地図を作ると、使っていない方が下がっていきます。そこで、新しいラインはすべて**その職業の既存の1か所**（転職で熟練を集める先）に置き、必要熟練で段を付けます。

| 職業 | 置き場 |
|---|---|
| 薬屋 | 薬調合入門 |
| 酪農家 | ミノ牛乳（熟練なし） |
| 本屋 | 本執筆キット |
| 行商人 | 剣市への地図 |
| 山師（木こり） | 近くの山への地図 |

既存品のレシピは変えません。追加だけです。

## 職の「型」で見る（全職を同じ強さにはしない）

目指すのは、全職を似た強さにすることではありません。役割で個性を分けます。
- **手間型**: 手間はかかるが高報酬
- **楽で強い型**
- **効果型**: 面白い効果を起こせる
- **手ごろ型**: 弱めだが操作が楽

### 分かったこと

- **型に合っていない職は3つです**。盾屋、装飾細工屋、酪農家（実質）です。どれも「手間型なのに報酬が足りない」ずれです。直すなら報酬側を上げます（手間は個性として残す）。
- **効果型に当たる職は、今はいません**。面白い効果を起こす行動は、次のとおり誰でも使えるか、職業ボーナスは時間短縮だけです。
  - 広告（人気アップ）
  - 禁断の書（噂・万引き）
  - ミノ牛乳を飲む（人気が少し上がる）

  芽があるのは次の2職です。
  - 行商人: 送付時間が半分で、広告も速い。
  - 酪農家: 乳製品で人気を上げられる。

  効果型を作るなら、この2職に「その職だけの効果」を持たせるのが近道です。たとえば行商人は買い取り募集の枠が多い、酪農家は乳製品を食べると人気が上がる量が多い、などです。0.3.x 以降の検討事項にします。
- **楽で強い型**は探鉱夫と行商人で、**手ごろ型**は木こりです。どちらもいまの数値で型どおりです。
