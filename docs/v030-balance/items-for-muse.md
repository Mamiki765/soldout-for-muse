## 6. つながり（どの職業がどこで関わるか）

- 行商人と山師が、砂糖・香辛料・霊草を集めます。
- 薬屋は、香油 → 香水・エリクシルを作ります。
- 酪農家は、牛乳 → ミノクリーム → 氷菓・焼き菓子を作ります。
- 本屋は、それぞれを作るのに要る2冊を書きます。
