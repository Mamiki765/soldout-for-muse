## 実装の注意（dump-items.pl）

- `production` / `gathering` は置き場の `uses[0]` をひな型に写します。置き場によって、ひな型の中身が新しい USE と合いません。
  - **剣市への地図(14)**: uses[0] に `func_before: _local_b1`（1割で収穫2倍）が付いています。新しい行き先では外してください。
  - **ミノ牛乳(26)**: uses[0] は「飲む」です（`func: _local_1`、exp 0）。func を外し、`get` と `okmsg` を付けてください。
  - **薬調合入門(15)・本執筆キット(10)・山の地図(12)**: ひな型どおりで大丈夫です。必要熟練は `needexp` に入れます。
- 「確率で消費する所持条件」（proba 30）は、いまの `tools` 指定（proba 0 固定）では書けません。材料の行に proba を書けるように広げてください。エンジン側（`use.ts`）は、0〜1000 の proba をすでに確率消費として扱います。
- seed-market は、更新履歴の先頭版の `new_items` のうち、plus が正の品だけに在庫を入れます。今回の新しい品は全部 plus が 0 以下なので、何も入りません。リリース直後は、行商人と山師が素材の入口になります。
