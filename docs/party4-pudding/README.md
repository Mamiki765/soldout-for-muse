## 3. 利益と並び (標準価格で評価、時間は職業なしの基本時間)

自分で搾乳する場合 (酪農家・ミノ20頭で「ハードに乳を搾る」、1回1時間で平均約20本) の時間込み:
ヨーグルト 約2,700円/時、**固めプリン 約3,500円/時**、チーズ 約4,100円/時、ミノクリーム 約7,300円/時。
プリンはヨーグルトとチーズの間に入り、ミノクリーム以上のラインは崩しません。

供給量 (酪農家): 自前の牛乳なら2時間で4個 (搾乳1時間で20本＋製造30分×2回)、牛乳を買えば製造だけで1時間4個。

## 4. 既存商品・生産職への影響

- 酪農家: 本なしで作れる品が1つ増える。いちばん稼ぎの低い職業の入門枠の底上げ (ヨーグルトより少し良い程度)。
- 行商人: 砂糖の買い手が増える (港町で買い付け)。酪農家と行商人の取引が増える方向。
- ヨーグルト・チーズ: 需要は品ごとに別なので客を奪わない。牛乳1本の使い道として、ヨーグルトより得・チーズより損。
- ジェラート・チーズケーキ: 本が要る上位品で、粗利/時が約10倍。重ならない。
- 牛乳を持たない店も、市場で牛乳と砂糖を買い、ミノ5頭を揃えれば作れる (全店公平)。

## 5. 卵について (既存素材の代替案と新素材案の比較)

| | 既存素材で作る (この PR) | 新素材「卵」を足す |
| --- | --- | --- |
| 材料 | ミノ牛乳＋砂糖 | ミノ牛乳＋卵＋砂糖 |
| 必要な追加 | なし | 卵の品データ・入手方法 (新しい家畜か行き先)・市場の扱い・アイコン・イベント |
| 影響 | 酪農家と行商人の間で完結 | 新しい供給ラインが1本増え、どの職業に付けるかの判断が別に要る |
| 依頼者の原文との関係 | 「ミノ牛乳あたりから作れる」に沿う | 本格的だが原文の範囲を超える |

既存素材で十分と判断しました。卵を足すなら、プリン以外の使い道 (焼き菓子など) と一緒に別件で設計するのがよいと考えます。

## 6. 「肉球萬屋の看板商品」について

品そのものは全店が同じ条件で作れて売れます。看板にするのは店側の工夫 (先頭の棚に置く・値付け・店の説明) で十分実現でき、ゲーム側で特定の店に結び付けることはしません。

## 7. 管理者に判断してほしいこと

1. 1回2個・2,200円 (この PR) か、ミュートA案 (1個・4,500円) か、B案 (5個×80%・2,200円) か。
2. 需要 popular 7,200 (ヨーグルトと同じ) でよいか。看板品として売れ残りにくくするなら 6,000 前後も候補。
3. 「使ったときの効果」なしでよいか (ミノ牛乳の「飲む」のような人気の増減を付ける案もある)。
4. 版番号と更新履歴・告知文。新品は自然入荷しないので `seed-market` の対象外で、`new_items` に入れても入荷はしません。
5. 名前・説明文の最終文面 (Muse が直す想定)。
