# 初回試作のGPT向け画像制作プロンプト

[美術設定と採用色](README.md) · [素材仕様と検品](assets.md#試作の検品)

初回は、街の材料と店主の色が同じ画面で読めるかを確かめる。GPTには共通指示を添えて、地形、橋、S店舗を順に依頼する。オーナーが確認した地形の原寸画像を橋と店舗の参照にする。最初の納品は**地形12枚、南北の大通り橋1組、S店舗2方向**。区画全体の絵や公共施設の意匠は後続グループで扱う。

## 共通指示

各依頼に次の文を添える。

```text
SOLD OUT Muse街 v1.2.0 の地図用ピクセルアートの試作を作ってください。
木組みと淡い漆喰の店が並ぶ、中世ファンタジーの川沿いの商い町です。
正方格子を上から見るRPG風。道路と川は画面の水平・垂直に通し、屋根面を大きく、正面の壁は短い帯で見せます。
左上（北西）から柔らかな昼光。接地影は右下に短く。光は素材や向きが変わっても同じです。

配色は A「焼き瓦と柳」。以下は素材ごとのsRGB基準色と、日向・陰などの補助色です。
草地 #9BAE80、芝 #AAB98D、土の路地 #B39A76、園路・敷居 #C2AE8C。
大通りの石畳 #B7AD98、明るい舗装 #CCC2AA、護岸 #A49A81。
川は水面 #688F92、短い反射 #8CAEB0、深み #4F7279。
橋は木床 #A78A68、石の橋台 #B2A58D、欄干 #6B5546。
赤瓦は日向 #B97A61、基準 #A36550、陰 #885346。
漆喰 #E6D7BD、壁の陰 #BDAE97、梁・戸枠 #76624D、明るい縁 #F0E3CA、樫の扉 #694F40。

面ごとに近い明暗を数段使い、小さいまとまりで石の目地、草の葉、瓦、水の反射を描きます。
背景の模様は控えめにし、隣に藍、山吹、葡萄などの屋根が並んでも店の色が読める明るさにしてください。
ピクセルは垂直・水平の格子に乗る輪郭。アンチエイリアス、ぼかし、遠近法の消失点、斜めのアイソメ、文字、UI、透かし、ガイド線は入れません。
素材は原寸へ切り出して検品します。原寸の指定どおりに出せない場合は縦横比、セルの配置と境界を保ち、作成した画像の寸法とセルの順を画像外の文章で示してください。
```

## 依頼1 草地、土路地、石畳、川岸

```text
次の12セルを、4列×3行の隙間なしの素材シート1枚にしてください。
各セルの最終寸法は32×32px、シートの原寸は128×96px。大きい画像なら同じ縦横比の整数倍にしてください。
セルは左から右、上から下の順で並べます。文字や枠、余白は置かず、全セルを不透明にしてください。

1行目　野草地の基本、野草地の控えめな差分1、野草地の控えめな差分2、手入れした芝。
2行目　土路地の中、土路地の北縁（上が芝・下が土）、土路地の南縁（上が土・下が芝）、大通りの石畳。
3行目　南北につながる店先の敷石（芝の上）、岸のない水面、川の北岸（上が陸・下が水）、川の南岸（上が水・下が陸）。

野草地3種の端は共通。小さな草の塊は内側に置き、繰り返しても模様が目立たない差にしてください。
路地の2つの縁は並べると東西に続く64px幅の道になります。両岸も縦に並べると64px幅の川になり、水面色が中央で自然につながります。
北岸・南岸は石積みの高さと水平の通りを揃え、左右に並べても水と石がずれないようにしてください。
岸のない水面は青緑を広く残し、反射を短くまばらに。石畳の目地は黒くせず、大きく並べたときに市松に見えないようにしてください。
```

## 依頼2 大通りの橋

```text
依頼1の石畳と川岸を参照し、東西に流れる川を南北に渡る、大通り幅の橋を1組作ってください。
最終外枠は横96×縦128px（幅3セル、長さ4セル）。北から順に、石の橋台1行、木床の水上区間2行、石の橋台1行です。
幅は左列の細い欄干、中央の通行面、右列の細い欄干で構成し、左右に伸びる川岸を塞がないようにします。

両端は石畳へ段差感なく通すため、入口を横切る柵や段、床の前に突き出す支柱は付けません。
水上の床板は一定の縮尺と色。同形の中間部を切り出したときに、床板と欄干が続く形にしてください。
橋台は陸側、橋床と欄干の必要な部分だけを描きます。周りの水面・草地・道は透明にしてください。
外周に落ちる影を描く場合は別候補として出し、橋本体に背景や大きな影を焼き込まないでください。
枠や説明の文字を加えず、橋の北端・南端と石畳の接続位置を画像外の文章で示してください。
```

## 依頼3 色を替えられる普通のS店舗

```text
依頼1の庭と石畳に置ける普通のS店舗を、南向きと北向きで各1枚作ってください。
最終外枠は各64×64px（2×2セル）、背景は透過、建物と付属物は外枠の内側。戸口の接続位置は幅中央で、南向きは下辺、北向きは上辺です。
切妻の赤瓦、淡い漆喰、木の梁、小さな木戸、一つか二つの窓、石の敷居、小さな無地の吊り看板。間口が一つの店舗兼住宅です。
南向きの戸口は手前の壁の短い帯に、北向きの戸口は奥側の庇と敷居で読ませてください。北向きでも光は左上です。
全体を同じ縦横比・材質・瓦の粒度にしてください。接地影や店用の日よけは、可能であれば別部品にしてください。

店主は屋根と扉を別々に色変更します。赤瓦の明暗と、樫の扉の明暗・木目を保持できるように、色が替わる範囲を明確にしてください。
屋根・壁・扉・縁の区分を画像外の文章で示し、可能であれば絵と同寸・同位置の部位見本を付けてください。
窓、蝶番、取っ手、看板の固定部、影には着色の境界をまたぐ描き込みを避けてください。
同じ南向きの絵で、屋根だけ藍 #4F6682 に替えた例と、扉だけ生成り #D8C7A8 に替えた例も示してください。構図と輪郭は固定です。
```

## 原寸化と確認用の組み方

- **Codexが揃える納品物。** 32角の原寸PNG12枚、96×128pxの橋1組、64角のS店舗PNG2枚、各Sの屋根・壁・扉・縁の部位マスク。生成画像から切り出し、必要な縮小・透過清掃・接続帯の修正をしてから検品する。画像生成で十分に揃わないマスクは、原寸の絵を基準に作り直す。
- **地形見本。** 草・芝を各5×5マス以上敷く。別の場面で東西に2マス幅の川を通し、南北の3マス幅の石畳に橋を接続する。岸が橋の下に重なって浮いて見える場合は橋の左右端を調整する。
- **店先見本。** 土の路地2行の上下に北向き・南向きのSを配置し、敷石を各戸口につなぐ。同じ形で屋根の赤瓦・藍・山吹と、扉の樫・深緑・生成りを比較する。変更した部位だけピクセルが変わることをマスクで確認する。
- **オーナーに見せる内容。** 原寸と2倍・4倍の最近傍表示、地形1マスが16px程度になる縮小表示。草・川・土路地の境、店先と橋の入口、屋根の明暗と複数色の見分けやすさを確認する。
