## 画風と生活感

- **視点と光。** 正方格子の上から見下ろすRPG風ピクセルアート。屋根面を広く、見える壁は短い帯にする。左上（北西）から柔らかな昼光、右下（南東）に短い影。北向きの建物でも光向きは共通にする。色のまとまりを数ピクセル単位で作り、縮小しても道筋と屋根が残る密度にする。
- **店舗兼住宅。** 石の基壇、淡い漆喰、木の梁、木戸、低い切妻屋根が基本。Sは一間口、Mは窓や脇棟、Lは棟や間口の分節で大きさを表す。とくにSでも戸口と屋根色が見えるようにする。路地側に小さな無地の看板や絵印を添え、店名・住所はUIで表示する。NPC住宅は日よけなどの店先部品を外して同じ街に馴染ませる。
- **交通と自然。** 大通りは暖かい灰色の割石、歩道は同系の明るい石、路地は踏み土。川の市街側は低い石積み、郊外では草や葦を交えてよい。橋は木床と石の橋台、細い欄干で入口を開ける。草地・芝・畑は色と模様の両方で分け、公園では芝や静かな園路が残るよう花・木を置く。
- **所有者の色。** 屋根と扉は独立して変更できる。プリセットは壁と縁も持てる。瓦や板は、日向、基準、陰、必要な目地の複数色で描く。色を替えても形・素材感・光向きを保つ。藍や葡萄、山吹、苔、明るい扉も背景に置いて確認する。白い壁や軒・戸枠で境を読めるようにし、店先の装飾は選んだ色を覆わない程度に置く。

## 採用パレット A 焼き瓦と柳

各HEXはsRGBの参照色。地面のゆらぎ、石の目地、瓦の影、水面の反射には近い補助色を使える。遠景では面が落ち着いて見え、近景では素材の違いが読める密度にする。

| 用途 | 基準色と補助色 |
| --- | --- |
| 野草地 / 芝 | `#9BAE80` / `#AAB98D` |
| 大通り / 歩道・広場 | `#B7AD98` / `#CCC2AA` |
| 路地 / 園路・敷居 | `#B39A76` / `#C2AE8C` |
| 畑・花壇の土 / 苗 | `#917457` / `#718555` |
| 川・池の水面 / 反射 / 深み | `#688F92` / `#8CAEB0` / `#4F7279` |
| 川岸の石 | `#A49A81` |
| 木の日向 / 葉 / 陰 | `#768D60` / `#56734F` / `#465C45` |
| 赤瓦の日向 / 基準 / 陰 | `#B97A61` / `#A36550` / `#885346` |
| 漆喰 / 陰、梁・戸枠 / 明るい縁 | `#E6D7BD` / `#BDAE97`、`#76624D` / `#F0E3CA` |
| 橋床 / 橋台 / 欄干 | `#A78A68` / `#B2A58D` / `#6B5546` |
| 花 / 金物の差し色 | `#BD7975` / `#C3A068` |

屋根の試験色は赤瓦 `#A36550`、藍 `#4F6682`、葡萄 `#7B5971`、苔 `#617852`、山吹 `#A17A46`、墨 `#535762`。扉の試験色は樫 `#694F40`、紺 `#3F536C`、渋赤 `#824D47`、深緑 `#496B55`、生成り `#D8C7A8`。これらは制作時に組み合わせを確かめる色。店主に見せる選択肢や任意色の扱いは素材の確認後に決める。

## 中央区の扱い

東西2チャンクと施設の位置はP0を基本とする。西は市場、役場、ギルド会館、大樹、噴水広場、掲示板、船着き場など。東は池・東屋・園路のある公園と将来の施設用地。間の石畳の中央軸は、道と橋を通す。予定地は花壇、遊歩道、小広場、緑地として使える部品の組み合わせで表す。 [P0の中央区](https://github.com/Mamiki765/soldout-for-muse/blob/2f3236d562ac028e16e2ace17be5135609930f12/tools/town-mock/README.md#L19-L26)

**公共施設は初期の街から配置する。** 機能の実装を待たず、美術制作を進められる。地図上の施設は、街の既存機能や将来の機能の受け皿になる。ゲームに市場、税、ランキングなどはあるが、地図の建物と各機能をつなぐ導線、一般向けに見せる街の統計、将来のギルド機能の内容・実装時期はこの資料では確定しない。現行機能は [API資料](../API.md) と [街の設定](../../README.md#街の設定) を参照。

| 施設 | 街での役割 | Aに沿った外観候補 |
| --- | --- | --- |
| 市役所（P0の街役場） | 税、街の統計、ランキングなどを扱う行政施設。 | 淡い石の基壇と段、温かい漆喰、赤茶の瓦。中央の時計や広めの入口で町の役所と読める。 |
| 中央市場 | 商取引の中心。 | 横長の木造大屋根と通り抜けられる柱間。生成りの屋台布に少量の黄土を配し、店の屋根色と競わないようにする。 |
| ギルド会館 | 将来のギルド機能の受け皿。 | 太い木組み、落ち着いた灰青の屋根、広い戸口。旗を付ける場合も小さくまとめ、紋章は後で決める。 |
| 噴水・大樹・掲示板 | 中央のランドマーク。 | 噴水は明るい石の縁と青緑の水、大樹は太い幹と深い緑の樹冠、掲示板は木枠に小さな紙札。それぞれ輪郭で識別できるようにする。 |
| 船着き場 | 川辺と市場の近くを結ぶ目印。 | 灰褐色の木の桟橋、石の取付け、係留杭と荷箱。 |
| 東の公園と予定地 | 公園として見せながら、将来の建設用地を自然に埋める。 | 芝、池、木造の東屋、園路を基本にする。予定地は花壇・遊歩道・小広場・緑地にし、建設時に外周の園路を残せるようにする。 |

**中央広場の舗装模様、装飾、公共施設の具体的な屋根・正面・色・紋章は未決。** 表の外観は候補。制作時にP0の施設位置と入口を保って提案し、オーナーが採否を判断する。P0の管理人店あり／なしの比較もこの資料では決定しない。
